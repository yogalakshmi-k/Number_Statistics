# Number Statistics Using Python

## 📌 Project Overview
This project is completed as part of the **Day 5 AI & ML Internship at Veda Technology**. It is a simple Python program that identifies even and odd numbers in a list and finds the largest and smallest values.

## 🎯 Objectives
- Identify even numbers from a given list.
- Identify odd numbers from a given list.
- Find the largest number.
- Find the smallest number.
- Practice Python loops, conditional statements, and basic data processing.

## 🛠️ Tools Used
- Python
- Google Colab
- GitHub

## 💻 Python Concepts
- Lists
- For loops
- If-else statements
- Modulo operator (`%`)
- `max()` and `min()` functions

## 📋 Sample Input
```python
numbers = [12, 7, 24, 9, 15, 32, 5, 18, 41, 10]
```

## ⚙️ Approach
1. Create a list of numbers.
2. Initialize separate empty lists for even and odd numbers.
3. Use a `for` loop to examine each number.
4. Use the modulo operator (`% 2`) to identify even and odd numbers.
5. Use `max()` and `min()` to calculate the largest and smallest values.
6. Display the results.

## ✅ Expected Output
```text
Original List: [12, 7, 24, 9, 15, 32, 5, 18, 41, 10]
Even Numbers: [12, 24, 32, 18, 10]
Odd Numbers: [7, 9, 15, 5, 41]
Largest Number: 41
Smallest Number: 5
```

## 📊 Results
The program successfully separates even and odd numbers and identifies the largest and smallest values in the given list.
